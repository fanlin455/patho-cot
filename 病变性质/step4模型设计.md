# Step4：病变性质判定模型设计文档

## 1. 任务定义

对一张病理切片图像，基于其中所有细胞的**空间分布、形态特征和纹理特征**，判定该切片整体处于**正常**还是**异常**状态。

| | 说明 |
|---|------|
| 输入 | 病理图像经 YOLO 检测后得到的所有细胞框（位置 + 尺寸） |
| 输出 | Normal（正常）或 Abnormal（异常） |
| 类型 | 图级别二分类 |
| 基线性能 | TestAcc 78.4%, AUC 87.4% |

## 2. 数据

### 2.1 数据来源

PanNuke 数据集经 YOLOv8 检测标注后的结果，覆盖 19 种人体器官组织。

| 子集 | 数量 |
|------|------|
| train | 6320 |
| val | 790 |
| test | 791 |
| **合计** | **7901** |

### 2.2 原始格式

每张病理图像对应一个 YOLO 标签文件（`.txt`），每行一个细胞：

```
class_id  x_center  y_center  width  height
```

其中 `class_id=0` 为病灶细胞（lesion），`class_id=1` 为非病灶细胞（non_lesion）。坐标和尺寸均为归一化值（0~1）。

## 3. 标签生成

### 3.1 问题

原始数据只有细胞级别的（病灶/非病灶）标注，没有图像级别的病变性质标签（正常/异常）。需要从细胞标注中构造图像级标签。

### 3.2 方法：lesion_ratio + GMM 二聚类

#### lesion_ratio

对每张图，计算病灶细胞占全部检测细胞的比值：

$$\text{lesion\_ratio} = \frac{\sum [class\_id = 0]}{总细胞数}$$

**直觉**：正常组织切片中病灶细胞散在且稀少，恶性组织则相反。病灶细胞占比在高/低两组间应呈现双峰分布。

#### GMM 自动确定边界

对 train 集 6320 个样本的 lesion_ratio 拟合 **2 分量高斯混合模型（GMM）**。取两个高斯分量后验概率相等处作为 Normal/Abnormal 的分界点：

$$\text{label} = \begin{cases} \text{Normal} & \text{if lesion\_ratio} < \text{GMM boundary} \\ \text{Abnormal} & \text{if lesion\_ratio} \ge \text{GMM boundary} \end{cases}$$

#### 实际结果

| 参数 | 值 |
|------|-----|
| GMM 分界 | 0.4936 |
| Normal 样本数 | 3764（47.6%） |
| Abnormal 样本数 | 4137（52.4%） |

分布接近 1:1，无需类别加权。

### 3.3 为什么不泄漏标签信息

> **关键设计**：`class_id`（病灶/非病灶）只用于生成标签，**不进入模型的节点特征**。模型无法通过简单统计病灶数量来"作弊"，必须从细胞形态、纹理和空间关系中推断病变性质。

## 4. 图构造

### 4.1 节点 = 细胞

每张病理图的每个检测到的细胞是一个节点。

### 4.2 节点特征（14 维）

| 维度 | 特征 | 计算方式 | 病理意义 |
|---:|------|----------|----------|
| 0–1 | 中心坐标 | `(cx, cy)` 归一化到 [0,1] | 细胞在图中的空间位置 |
| 2 | 面积 | `w × h` | 细胞核大小 |
| 3 | 长宽比 | `max(w,h)/min(w,h)`，裁剪到 [1, 5] | 细胞核形态（恶性→不规则） |
| 4 | 局部密度 | `1 / (到最近5个邻居的平均距离 + ε)` | 局部细胞拥挤度（肿瘤→密集） |
| 5–7 | RGB 均值 | 细胞 patch 三通道均值 / 255 | 核染色深浅（恶性→深染） |
| 8–10 | RGB 标准差 | 细胞 patch 三通道标准差 / 255 | 染色质纹理粗糙度 |
| 11 | GLCM 对比度 | 灰度共生矩阵对比度 / 100 | 核内纹理复杂度 |
| 12 | GLCM 同质性 | 灰度共生矩阵同质性 | 核内纹理均匀度 |
| 13 | GLCM 能量 | 灰度共生矩阵能量（ASM） | 核内纹理规则性 |

### 4.3 邻接矩阵（边）

对图内任意两个细胞 `i, j`，边由空间距离决定：

$$A_{ij} = \begin{cases} 1 & \text{if } \text{dist}(i, j) \le \text{threshold} \\ 0 & \text{otherwise} \end{cases}$$

**自适应阈值**：取所有细胞对上三角距离的 30% 分位数，确保无论器官类型和图像分辨率，约 30% 的细胞对之间存在边。

**归一化**：使用 GCN 标准对称归一化 `D^{-0.5}(A+I)D^{-0.5}`。

## 5. 模型架构

```
输入: (N, 14) 节点特征 + (N, N) 邻接矩阵
  │
  ├─ GCN Layer 1: 14 → 128    + LayerNorm + ReLU + Dropout(0.3)
  ├─ GCN Layer 2: 128 → 128   + LayerNorm + ReLU + Dropout(0.3) + 残差连接
  ├─ GCN Layer 3: 128 → 64    + LayerNorm + ReLU + Dropout(0.3)
  │
  ├─ AttentionReadout: 单头注意力加权池化 → (1, 64)
  │
  └─ 分类器: Linear(64, 32) + ReLU + Dropout(0.3) + Linear(32, 2)
```

### 参数量

约 **3.2 万**。

### 组件说明

| 组件 | 作用 |
|------|------|
| **GCN Layer** | 每层执行 `ReLU(LayerNorm(Adj · Linear(H)))`，查询一阶邻居信息 |
| **残差连接** | 维度假相同时（GCN2）加 `H + H'`，避免深层网络退化 |
| **LayerNorm** | 稳定节点特征分布 |
| **AttentionReadout** | 为每个节点学习一个注意力权重 `α_i`，加权求和 `Σ α_i · h_i` 得到整图的向量表示 |
| **Dropout(0.3)** | 节点特征级正则化 |

## 6. 训练策略

| 配置 | 值 |
|------|-----|
| 优化器 | AdamW（weight_decay=1e-4） |
| 初始学习率 | 0.001 |
| LR 调度 | CosineAnnealingLR（T_max=100） |
| Batch size | 32 |
| 损失函数 | CrossEntropyLoss |
| 早停 | patience=15，监控 ValAcc |
| Epochs | 最多 100 |
| Train/Val 划分 | 80/20 分层（stratified） |

> **设计说明**：模型参数仅 3.2 万，数据量 5000+，不存在过拟合风险，因此未使用 LabelSmoothing、EdgeDropout 等额外正则化手段。实验证实这些手段反而轻微削弱了测试集性能。

## 7. 版本演进

| 版本 | 分类 | 核心改动 | TestAcc | AUC |
|------|------|----------|---------|-----|
| **v1** | **二分类** | GMM边界 + 14维纹理特征 + 单头注意力 | **78.4%** | **87.4%** |
| v2（实验） | 二分类 | MultiHead注意力(4头) + hidden_dim=192 + EdgeDropout | 76.7% | — |

> v2 尝试增大模型容量并引入多头注意力和边丢弃正则化，参数量从 3.2 万增至 8 万，但测试集性能反而退步 1.7%。原因在于模型容量超出了当前数据量（~5000 样本）的上限，过多参数导致过拟合。该方向暂时搁置。

## 8. 执行流程

```powershell
# 1. 预处理（GMM 聚类 + 特征提取 → .pt 文件）
python preprocess.py

# 2. 训练
python train.py

# 3. 评估（混淆矩阵 + ROC + 概率分布）
python evaluate.py

# 4. 可视化（单样本图结构）
python visualize.py --index 5
```

## 9. 与 Web 引擎对接

`patho_cot_web/engine.py` 通过动态 `sys.path` 导入本模块的 `PathlogyGCN` 类和 `preprocess.py` 的特征提取函数。推理时：

1. 调用 YOLO 获取检测框
2. 调用 `extract_node_features()` 提取 14 维特征
3. 调用 `build_adjacency()` 构建邻接矩阵
4. 构造 `PathlogyGCN(hidden_dim=128, num_classes=2)` 并加载 `gcn_nature_model.pth`
5. `model([x], [adj])` 得到 Normal/Abnormal 二分类结果
