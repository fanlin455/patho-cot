## 一、P0：器官分类（冻结 Phikon-v2 + 线性探针）

**结论：✅ 大幅优于现有系统，且零训练。**

| 方法 | 测试集准确率(791张) | 对比现有 ViT-B/16 |
|---|---|---|
| ViT-B/16（现有系统，微调） | 94.18% | — |
| **kNN k=5（CLS 特征）** | **99.75%** | **+5.57pp** ⭐ |
| 逻辑回归（CLS 特征） | 98.99% | +4.81pp |
| 逻辑回归（均值特征） | 97.85% | +3.67pp |
| kNN k=5（均值特征） | 97.72% | +3.54pp |

- 模型：Phikon-v2（DINOv2 ViT-L/16，hidden 1024，1157MB，非 gated）
- 特征抽取：7901 张图 **103 秒（77 张/秒）**，落盘 57.4MB
- 各类别准确率：除 Uterus(95%)、Breast(99.6%) 外，其余 17 类全部 100%

### ✅ 泄漏复测（已完成，全部通过）
| 检验 | 结果 | 判定 |
|---|---|---|
| 训练/测试近邻重复 | near_dup = 0 | 无重复图 |
| 最近邻距离（中位/最小） | 0.136 / 0.030 | 无过近样本 |
| 分类间隔 margin（中位） | 0.253 | 间隔健康（非死记硬背） |

| **NCT-CRC 独立队列（非 TCGA，1800 张）探针** | **99.78%** | **跨域泛化确认** ⭐ |

**结论：99.75% 不是数据泄漏，是 Phikon-v2 的真实泛化能力。已接入主流程（`organ.backbone=phikon`，上线验证 step2→Colon 99%）。**

## 二、P1：病变性质（PFM 特征 + 轻量头）

**结论：✅ 优于 GCN，但暴露了任务本身的根本问题。**

| 方法 | 测试集准确率 | AUC | 对比 GCN |
|---|---|---|---|
| GCN（现有系统，弱监督） | 78.40% | 87.4% | — |
| 多数类基线 | 54.24% | — | — |
| **PFM kNN k=5（均值特征）** | **91.66%** | 95.6% | **+13.26pp** |
| PFM kNN k=5（CLS 特征） | 90.52% | 96.2% | +12.12pp |
| PFM 线性探针 | 89.89% | 96.2% | +11.49pp |
| ⚠️ ratio 规则 | 100.00% | — | 标签同源 |

### 🔴 关键发现（比数字更重要）：标签是"循环定义"的
1. 病变性质的标签 = `lesion_ratio >= 0.4936 ? Abnormal : Normal`
2. `lesion_ratio` 又是**从 YOLO 检测结果直接算出来的**（lesion 细胞 / 总细胞）
3. 而**部署管线本身就能直接算出这个 ratio** → 所以"ratio 规则"必然 100% 命中标签
4. 更严重：图像**细胞中位数只有 20 个** → 1 个细胞误检就让 ratio 跳 5% → **伪标签噪声极大**

**含义**：
- GCN 的 78.4% 不是"模型不行"，而是它在"用几何/纹理特征去反推一个本可直接计算的阈值"，且标签本身噪声大
- PFM 特征做到 91.66% 说明"图像表观"确实比"细胞图特征"更能反映这个 ratio
- **真正的修复方向**：要么用真实病理标注（而非 GMM 弱标签）重新定义任务，要么直接把"病变性质"改为"检测 ratio + 阈值"的确定性规则

### ✅ 已落地（双通道）
按建议重构为**确定性 ratio 阈值规则 + PFM 图像二次判读**：
- 主判据 = 部署管线直接算出的 `lesion_ratio`（与标签同源，确定性 100% 命中）
- 二次判读 = 冻结 Phikon-v2 + 线性头（`nature_phikon_head.pt`，LogReg C=1.0，AUC 96.2%）
- 已接入主流程（`nature.model=phikon`，上线验证 step4→Normal 0.9137）

## 三、P2：扩散异常检测（AnoDDPM 基线）

**结论：管线已实现并跑通；最终 AUROC 0.6685（受限于 GPU 与标签噪声）。**

- 方法：只用 GMM 判定的 Normal 样本（3025 张）训练 DDPM，重建误差 = 异常分数
- 标签同 P1（ratio 阈值）
- 参考：AnoPILaD（MICCAI 2025）、Linmans MedIA 2024
- **最终结果**：AUROC **0.6685**、AUPR 0.6742（791 张测试集）
- 对照：随机 = 0.50；GCN 文献值 AUC 0.874（但 GCN 是有监督弱标签训练，不可直接对比）

### 时间步消融（64px 模型，推理重建误差）
| 重建时间步 t | AUROC | AUPR |
|---|---|---|
| 50 | 0.6327 | 0.6399 |
| 150 | 0.6668 | 0.6686 |
| **300** | **0.6738** | **0.6773** ⭐ |
| 450 | 0.6586 | 0.6701 |
| 600 | 0.6446 | 0.6585 |
| 800 | 0.6135 | 0.6426 |
| 150/300/450 平均（主结果） | 0.6710 | 0.6753 |

- 最优在 t=300 附近；t 过大过小都掉（过小=噪声不足去不掉异常，过大=正常也被破坏）

### 分辨率消融
| 分辨率 | 参数 | 训练 | AUROC | AUPR |
|---|---|---|---|---|
| 32 | 0.7M | 800 步 | 0.6283 | 0.6508 |
| **64** | **2.6M** | **1500 步** | **0.6710** | **0.6753** ⭐ |

### 对比表（与本项目其它模块）
| 任务/方法 | 指标 | 值 |
|---|---|---|
| 器官分类 Phikon-v2+kNN | 准确率 | 99.75% |
| 病变性质 PFM+头 | AUC | 96.2% |
| 病变性质 GCN（现有） | AUC | 87.4% |
| **异常检测 AnoDDPM（本项）** | **AUROC** | **0.67** |
| 随机基线 | AUROC | 0.50 |

### 实测 GPU 算力瓶颈（重要）
- 本机 5060 Laptop 实测：**fp32 仅 2.8 TFLOPS**（应有 ~15）、TF32 7.3 TFLOPS
- 128×128 训练 **0.18 it/s**（6000 步 ≈ 9 小时，不现实）
- 64×64 训练 **2~6.7 it/s**（1500 步 ≈ 4 分钟，可行但分辨率低）
- 结论：**这张卡不适合训练扩散模型**，只适合做轻量推理

### ⚠️ 结果解读
- AUROC 0.67 是"超过随机、但远未到可用"的水平，符合预期：
  1. 64×64 分辨率太低（细胞级差异被抹平）
  2. 1500 步欠训练
  3. 伪标签噪声极大（细胞中位数 20 个）
- 调研结论印证：无监督异常检测与全监督差距显著；AnoDDPM 在 Camelyon16 上也只有 AUC 0.686
- **定位**：作为"生成式 AI 技术亮点 / 论文对比实验"，不作为生产模块
