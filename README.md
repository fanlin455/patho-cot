# Patho-COT 智能病理诊断系统

Patho-COT 是一个面向科研和教学演示的病理图像分析系统。它使用 FastAPI 提供 Web 界面，将图像质量检测、器官分类、细胞检测、病变性质判定、组织亚型分类和中文报告生成串联为六步流程。

**在线项目展示：** <https://fanlin455.github.io/patho-cot/>

> 医疗声明：本项目仅用于科研、教学与技术演示，不可替代病理医师的专业诊断。请勿向公开演示环境上传可识别患者身份的数据。

## 主要能力

- 病理图像质量检测：对焦、染色、组织占比和可用性评分
- 器官分类与 Top-5 概率展示
- YOLO 细胞检测，可选 SAM 像素级分割
- 病变性质与组织亚型分类
- 单图六步引导式诊断与多图批量分析
- 本地大模型生成结构化中文报告

## GitHub Pages 与完整后端的区别

`docs/` 是可直接托管在 GitHub Pages 的静态展示站。GitHub Pages 不运行 Python、FastAPI、CUDA 或模型推理，因此线上页面用于介绍和界面预览，不提供真实诊断。

完整后端需要：

- Windows 10/11，Python 3.10–3.12
- NVIDIA GPU，建议显存不低于 8GB
- CUDA 12.8 兼容驱动
- 约 12GB 磁盘空间（模型与 Python 依赖）

## 本地运行

1. 准备本项目所需的模型权重，按 `使用说明.md` 的目录结构放置。
2. 在 Windows 上双击 `一键安装依赖.bat`。
3. 安装完成后双击 `启动系统.bat`。
4. 打开 <http://127.0.0.1:8001/>。

也可在已配置好依赖的环境中启动：

```powershell
$env:PATHO_COT_MODEL_ROOT = (Get-Location).Path
Set-Location patho_cot_web
python -m uvicorn app:app --host 0.0.0.0 --port 8001
```

## 模型文件

大模型权重、训练产物、历史数据库、用户上传和生成结果均不推送到 GitHub：

- GitHub 普通 Git 对大文件有限制；
- 历史数据和上传内容可能包含隐私信息；
- Phikon v2 和 Qwen2.5 应根据各自模型许可证从原始发布渠道获取。

必需目录结构和完整安装步骤见 [`使用说明.md`](./使用说明.md)。

## 对外部署建议

如需让外网用户真正上传图片并运行推理，需将这个仓库部署到具备 NVIDIA GPU 的服务器，并在公网开放前增加服务端身份验证、HTTPS、上传限制、隐私保护和数据清理策略。
